# VN-W01 NCHMF 接入建议（草案，待 dots 审核后再写代码）

参照 MY-W01 有限接入口径：**只做官方公告展示，不做港口精确预警**。

1. Provider `nchmf`：只读抓取固定入口 index.html，按标题白名单挑预警类 post，再抓详情页；保存原文标题、正文、`postNNNNN`、原文时间字符串、抓取时间。
2. 身份：`weather-alert:nchmf:<postId>`；新 post 视为新记录，不推断替代/取消。
3. 时间：原文时间字符串原样保存，标记“时区未确认”“有效性待确认”，不计算是否生效；不用“下一期发布时间”当失效时间。
4. 级别：官方级别“未提供”；若正文有“Cấp độ rủi ro thiên tai … cấp N”，仅作为原文字段展示，不映射 severity、不触发 WR-O01/O02。
5. 区域/港口：无结构化区域 → 不关联港口（含 VNSGN），零影响；VNSGN 已验收参考点与 VN-W02 不动。
6. 失败语义：非 200/网络错误 = 失败；200 但正文空 = 视为失败（不是“无预警”）；列表无预警链接 = 空，带“无法区分确无预警/页面改版”说明。
7. 默认关闭（实验开关），不进 HOT，只进 Feed；测试用本次 raw 样本作夹具（含空正文 200 负例）。
