## 商业船期与其他数据源

承运人计划挂港、点到点路线、服务/航次和 ETD/ETA，与 AIS 当前航行状态分别建模。优先选择实际使用承运人的正式接口，逐个核对准入、费用、配额和服务范围；采用 DCSA 字段规范不代表自动获得数据。免费网页查询、试用额度和永久免费 API 必须分开标识。尚未找到经本项目验证的、无需授权且长期免费覆盖全部目标航线的统一商业船期 API。

- DCSA 标准：https://dcsa.org/standards/commercial-schedules
- 准入说明：https://dcsa.org/newsroom/commercial-schedules-standard-explainer
- 马来西亚官方天气 API 可补充天气预报和预警，但官方文档明确不提供 marine forecast，不能替代海浪预报或港口关闭公告：https://developer.data.gov.my/realtime-api/weather

## 全文与追溯

目标流程：资讯发现 → 原站正文获取 → 原文快照/版本 → 按结构分块 → 翻译和质量检查 → 原文/中文/对照详情页。全文任务通过现有服务端 Runtime 边界执行；GET 只读数据库/缓存，不触发即时模型账单。

每条内容保存来源机构、原文 URL、规范 URL、发布日期/更新时间、抓取时间、原始语言、正文哈希和版本；译文保存对应原文版本、段落/块 ID、模型、翻译时间和完成状态。新闻、公告和预警保留原文；数值指标保存供应商出处、指标定义和观测时间。来源引用其他公告时保留可核实关联，不伪造所谓一手来源。

完整翻译应覆盖获取到的完整文章主体、标题、列表、表格和图注，保留数值、时间、港名、船名、IMO/MMSI、航次及原始链接。不截断前若干段，不拿摘要冒充全文。原网页无法完整获取或需要授权时，显示受限/仅摘要/提取不完整；部分块失败必须显示部分完成，不让模型补写缺失段落。抓取内容是数据，不是可执行指令；抓取需校验域名、重定向和内容类型，不访问内网或绕过登录/付费限制。对外展示全文还需核对内容来源许可。

复用已有 DeepSeek 预算、缓存与重试机制，不新增未经评估的翻译供应商。正文及块级状态的具体 schema/API 变更需明确并采用增量迁移，不改写原始事实或 HOT 排序。
